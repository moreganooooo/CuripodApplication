# Curipod application portfolio

I built this microsite as part of an application for an Account Executive role at Curipod. It pairs examples from my work in education sales with a writing exercise about introducing a classroom tool to different people in a school district.

[Open the application site](https://moreganooooo.github.io/CuripodApplication/)

## Start with the writing sample

How would you explain the same product to a teacher, a technology director, and a curriculum director? I wrote a pitch for each reader, changing the details I led with to reflect what each person needs to know.

[Read the three pitches](https://moreganooooo.github.io/CuripodApplication/curipod_answers.html)

The [field stories](https://moreganooooo.github.io/CuripodApplication/#stories) cover outreach, segmentation, and onboarding from my work at Treering.
